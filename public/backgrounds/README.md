# 背景图片文件夹

这个文件夹用于存放登录页面的背景图片。

## 使用说明

### 上传背景图片
1. 在登录页面右上角点击"上传背景图"按钮
2. 选择您想要设置的背景图片（支持 JPG、PNG、WebP 等格式）
3. 图片会自动设置为登录页面背景

### 推荐的背景图片规格
- **分辨率**: 1920x1080 或更高
- **格式**: JPG、PNG、WebP
- **文件大小**: 建议不超过 5MB
- **比例**: 16:9 或接近的宽屏比例

### 图片效果
- 图片会自动适配屏幕大小（cover模式）
- 会添加半透明黑色遮罩层，确保文字清晰可读
- 登录卡片会有毛玻璃效果（backdrop-blur）

### 本地文件存放
您也可以直接将图片文件放在这个文件夹中，然后修改代码引用：

```javascript
// 在 app/page.tsx 中设置默认背景图
backgroundImage: '/backgrounds/your-image.jpg'
```

## 文件夹结构
```
public/backgrounds/
├── README.md          # 说明文档
└── (您的背景图片)      # 上传的背景图片
```
